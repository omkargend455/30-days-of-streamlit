## Day 20 – What is Streamlit?

Streamlit is a Python framework used to build interactive web applications for data science, machine learning, and AI projects.

Key points:
- Converts Python scripts into web apps
- No frontend required
- Ideal for dashboards, ML tools, and prototypes
- Fast development and deployment

Use cases:
- Data dashboards
- Machine learning model interfaces
- AI tools (chatbots, PDF Q&A, etc.)
